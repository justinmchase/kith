# kith-runtime

Library crate for [Kith](https://github.com/justinmchase/kith): check and run a
`Program` (instance tree, mailboxes, turns, host boundary, and `kith:` modules).

Operators install the `kith` CLI from GitHub Releases. Languages link this crate
from crates.io; they do not shell out to the binary.

```toml
kith-runtime = "0.1.0"
```
