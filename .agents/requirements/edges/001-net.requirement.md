# Net

## Requirement

Preconditions:

- A program imports `Socket` and `Listener` from `kith:net` and constructs
  one of each.

Expected behavior:

- `"Connect" host port` MUST later reply `"Connected"` or `"Error" reason`.
  `"Pull"` MUST reply `"Chunk" bytes` or `"End"`. `"Push" bytes` MUST reply
  `"Pushed"`. `"Close"` MUST reply `"Closed"`.
- A second `"Pull"` while one is in flight MUST reply `"Error" "busy"` and
  the first pull MUST stay in flight. An unknown command MUST reply
  `"Error" "unknown"` and MUST NOT clear that pull.
- `"Listen" host port` MUST reply `"Listening" host port` with that host
  and the bound port. A second `"Listen"` MUST reply with that listen's
  pair. An accepted
  connection MUST be `"Connection" id`. `"Pull" id`, `"Push" id`, and
  `"Close" id` MUST carry that id on the reply. A second pull of the same
  id MUST reply `"Error" id "busy"`.
- `run_until_idle` MUST NOT block on the connect. Snapshot MUST restore a
  scripted in-flight pull.

Postconditions:

- Tests: `tests/edges.rs` (`req:edges-001`).
