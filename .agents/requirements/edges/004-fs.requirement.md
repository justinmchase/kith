# Fs

## Requirement

Preconditions:

- A program imports `File` from `kith:fs` and constructs one `File`.

Expected behavior:

- `"Open" path "read"` MUST reply `"Opened"`, and `"Pull"` MUST reply
  `"Chunk" bytes` of at most 4096 octets, then `"End"`.
- `"Open" path "write"` MUST replace the file. `"Push" bytes` MUST reply
  `"Pushed"` and `"Close"` MUST reply `"Closed"`. A missing parent MUST
  reply `"Error" "missing parent"`.
- `"List" path` MUST reply name chunks in sorted order, one level, then
  `"End"`. `"Remove" path` MUST reply `"Removed"`.
- A second `"Pull"` while one is in flight MUST reply `"Error" "busy"`.

Postconditions:

- Tests: `tests/edges.rs` (`req:edges-004`).
