# Incremental id

## Requirement

Preconditions:

- A program evaluates `(id)` in a handler. It does not import `id`.

Expected behavior:

- The first `(id)` MUST be `000000000000000000000001`. The second MUST be
  `000000000000000000000002`. The text MUST be 24 lowercase hex digits, and
  the second MUST sort after the first.
- Count `16777215` MUST be `000000000000000000ffffff`. Count `16777216`
  MUST be `000000010000000000000000`. The second of those MUST sort after
  the first.
- Snapshot `idCounter` MUST be the decimal count of ids already returned.
  Restore MUST continue from that count. A snapshot that omits `idCounter`
  MUST restore as zero, so the next `(id)` is the first id.
- When `idCounter` is `72057594037927935`, the next `(id)` MUST fail with a
  message containing `exhausted` and MUST leave `idCounter` unchanged.
- `(id 1)` MUST fail the expression. The call MUST NOT change the next
  `(rand Lo Hi)` result. Starting a component that does not evaluate `(id)`
  MUST leave `idCounter` at zero. The call MUST NOT read a clock.

Postconditions:

- Tests: `tests/stdlib.rs` (`req:runtime-007`).
